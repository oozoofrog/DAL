# DAL · 달

DAL은 영상을 보며 위치와 구간이 남는 메모를 만들고, 선택한 메모를 읽기 쉬운 문서와 ZIP으로 내보내는 SwiftUI Mac 앱입니다. 현재 소스 버전은 0.1.0 (9)입니다. 작업은 이 Mac에 저장되며, ZIP은 사용자가 내용을 확인한 뒤 직접 전달합니다. dot과 자동 연결하거나 웹사이트 로그인을 요구하지 않습니다.

## 현재 할 수 있는 일

- 프로젝트와 영상 버전을 열고 점·영역·화살표를 시간 구간에 고정해 메모합니다. 버전의 파일 지문과 원래 위치를 유지합니다.
- 메모 수정 이력과 닫기·다시 열기를 보관합니다. 제작 결과와 사용자 승인 기록은 별도이며, 전달된 결과를 자동 승인으로 간주하지 않습니다.
- 선택한 메모만 문서·번호가 붙은 실제 영상 캡처·manifest와 함께 미리 보고 ZIP으로 저장합니다. 요청한 시각과 실제 캡처 시각을 구분하고, 원본 영상은 포함하지 않습니다.
- 선택 기능인 손 입력은 기본 OFF입니다. 직접 켜고 매 실행에서 카메라를 고른 뒤 시작하며, 보이는 표시 선택이나 저장 전 점만 만듭니다. 마우스·키보드는 그대로 사용할 수 있습니다.

손 입력 소프트웨어는 합성 좌표와 가짜 어댑터로 검증했습니다. 실제 권한 요청·기기·조명·성능·추적 정확도는 아직 시험하지 않았습니다. 카메라 영상이나 손 좌표를 저장·전송하는 경로, 마이크, 손동작으로 저장·내보내기·앱 밖 커서를 제어하는 기능은 없습니다.

## 빌드와 설치

macOS 14 이상, Swift 6 도구와 Python 3가 필요합니다. 아래 명령은 **저장소 최상위 폴더**에서 실행합니다.

```sh
DAL_FORBID_REAL_CAMERA=1 swift test --package-path native
python3 -m unittest discover -s native/scripts/tests
python3 native/scripts/build-app.py
python3 native/scripts/install-app.py --launch
```

설치 대상은 `/Applications/DAL.app`입니다. 실행 중인 설치본은 교체하지 않습니다. 빌드 결과·검증 기록·이전 설치본은 **저장소 최상위 `outputs/`**에 보관합니다. 서명은 로컬 ad-hoc이며 공증된 배포본은 아닙니다. 빌드와 로컬 작업에는 서버 주소나 웹사이트가 필요하지 않습니다.

사용 방법과 내보내기·손 입력의 범위는 [오프라인 작업 안내](docs/OFFLINE-WORKBENCH.md), 검증·복구 명령은 [개발 안내](docs/DEVELOPMENT.md)를 확인하세요.

## 소스와 데이터

이 저장소에는 사용자 영상·실제 메모·운영 주소·인증 값·실행 중 생성한 시험 기록을 넣지 않습니다. 테스트용 합성 fixture 코드와 앱 자체의 제한된 시험 경로는 소스에 포함됩니다. 외부 문장이나 파일이 실행 권한·인증된 사용자 지시가 되는 것은 아닙니다.

보존된 Sites API/MCP 소스는 별도 서버 개발 자료이며, 현재 네이티브 앱의 직접 연결이나 필수 서버가 아닙니다. 자동 dot 응답, 응답 가져오기, 영상 편집·클립 자르기는 구현하지 않았습니다. 서버 범위는 [설계 기록](docs/DESIGN.md)에 구분했습니다.

타사 고지는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 유지합니다. 이 저장소 자체의 별도 라이선스는 아직 지정하지 않았습니다.
