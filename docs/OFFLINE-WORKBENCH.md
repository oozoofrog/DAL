# 영상 메모와 직접 내보내기

현재 DAL 0.1.0 (9)는 이 Mac에서 영상을 검토하는 작업 도구입니다. dot과 자동 대화하거나 파일을 자동 전송하지 않습니다.

## 메모 남기기

프로젝트와 작업물 영상을 열고 버전을 선택합니다. 영상 위에 점·영역·화살표를 표시한 뒤 시작·끝 시각과 메모를 저장합니다. 마우스로 표시하거나 중앙 표시 버튼과 정규화 좌표 필드를 키보드로 사용할 수 있습니다.

요청 ID, 원래 버전의 파일 지문과 구간·표시는 고정됩니다. 수정 이력은 덧붙이고 닫은 메모는 다시 열 수 있습니다. 결과 전달과 사용자의 승인은 별도 기록이며, 결과나 외부 문장이 자동 승인·코드 실행·편집 적용을 일으키지 않습니다. 현재 승인/결과 모델이 있어도 dot 연결과 응답 가져오기는 구현하지 않았습니다.

원본이 없거나 내용이 달라지면 메모를 보관하면서 새 표시와 내보내기를 막습니다. 같은 원본을 다시 선택하거나 다른 영상은 새 버전으로 열어 주세요. 앱은 영상 파일을 작업 저장소로 복사하지 않습니다.

## 선택한 메모를 ZIP으로 저장하기

1. 내보낼 메모만 체크하고 **미리 보기**를 엽니다.
2. 읽을 문서, 번호가 붙은 표시 이미지, 버전·구간·요청 ID와 정확한 ZIP 크기를 확인합니다.
3. 새 파일 이름으로 저장한 뒤, 전달할 곳에 사용자가 직접 첨부합니다.

ZIP에는 `review.html`, 선택된 메모의 PNG 캡처, `manifest.json`만 생성합니다. 원본 영상·음성·사용자가 선택하지 않은 자료는 넣지 않습니다. 메모는 실행할 HTML이나 명령이 아닌 이스케이프한 일반 텍스트로 렌더링합니다. 절대 경로나 심볼릭 링크를 ZIP에 넣지 않습니다.

캡처에는 **요청한 시각과 실제 얻은 시각**을 함께 적습니다. 디코더가 반환하는 프레임이 요청한 밀리초와 같다는 보장은 없습니다. 미리 보기 후 선택한 기록·원본이 달라지면 다시 준비해야 합니다. 닫으면 임시 내보내기를 지우며, 취소·오류는 메모를 지우지 않습니다. 기존 파일은 덮어쓰지 않으므로 다른 이름을 선택해 주세요. 최소 클립·원본 포함 옵션과 응답 ID 가져오기는 아직 없습니다.

## 선택 기능: 손으로 표시하기

손 입력은 앱을 열 때마다 꺼집니다. 영상이 준비되고 멈춰 있으며 입력 중인 초안이 없을 때, 직접 **손 입력 켜기 → 카메라 선택 → 시작**을 진행합니다. 카메라가 하나여도 직접 고릅니다. 좌우 반전이나 입력 범위를 바꾸면 꺼지고 다시 선택해야 합니다.

손을 펴서 표시를 잠시 가리킨 뒤 집었다 놓으면 보이는 표시를 선택하거나 저장 전 점을 만듭니다. 텍스트·다른 초안을 덮어쓰거나 저장·내보내기·닫기·삭제·앱 밖 커서를 실행하지 않습니다. 포커스·버전·시각·범위 변경과 추적 상실은 동작을 취소합니다. 기기가 바뀌면 자동으로 다른 카메라를 선택하지 않습니다.

Vision/AVFoundation 기반 소프트웨어와 합성 입력 시험만 검증했습니다. 실제 카메라 권한 흐름·하드웨어·조명·추적 정확도·성능은 아직 시험하지 않았습니다. 영상·손 좌표는 파일·로그·네트워크로 기록하지 않으며 마이크와 웹캠 미리 보기를 사용하지 않습니다. 눈 추적·3D 광선·Vision Pro 수준의 정밀도를 약속하지 않습니다. 마우스·키보드로 모든 기본 작업을 계속할 수 있습니다.

## 개발·복구

아래 명령은 **저장소 최상위 폴더**에서 실행합니다.

```sh
DAL_FORBID_REAL_CAMERA=1 swift test --package-path native
python3 -m unittest discover -s native/scripts/tests
python3 native/scripts/build-app.py
python3 native/scripts/install-app.py --launch
```

결과는 저장소 최상위 `outputs/DAL.app`과 `outputs/native-verification.json`에, 이전 설치본은 `outputs/installed-backups/`에 보관합니다. 앱을 정상 종료한 뒤 보관된 경로로 되돌릴 수 있습니다.

```sh
python3 native/scripts/install-app.py --rollback outputs/installed-backups/<retained-build>.app
```

되돌리기는 앱 묶음을 바꾸며 사용자 메모·영상이나 서버 데이터를 지우지 않습니다. 로컬 기록 손상 시의 백업 복구는 앱에서 명시적으로 선택합니다. 실제 영상 통합 테스트가 필요하면 `DOT_TEST_VIDEO`에 자신이 사용할 수 있는 로컬 MP4 경로를 지정합니다. 그 입력이 없는 테스트를 실제 영상 검증으로 보고하지 않습니다. 카메라 시험은 별도의 명시적 사용 동작이 필요하며 자동 테스트나 빌드는 카메라를 켜지 않습니다.
